Welcome to the tutorials! This section teaches you how to use Velora for your own experiments.

If you are new to Velora, we highly recommend working through the [Essentials](#essentials) to get comfortable with the basics. Each tutorial builds on the other to help you gain a better understanding of each concept and become a Velora master in no time! :wink:

## Prerequisites

These tutorials assume:

- Python 3.12+ is installed with Velora. If not, refer to :point_right: [Getting Started](../starting/index.md)
- Basic familiarity with [PyTorch [:material-arrow-right-bottom:]](https://docs.pytorch.org/docs/2.11/index.html)
- Comfort with Python [dataclasses [:material-arrow-right-bottom:]](https://docs.python.org/latest/library/dataclasses.html)

If any of that is unfamiliar, we highly recommend referring to the linked resources first and come back once comfortable. You'll get more out of the tutorials that way!
